Generated by `experiments/run_calphad_grid_fd_gradient.py`; every number below is computed from `derivative_fidelity.csv`, `derivative_fidelity_summary.csv`, `derivative_fidelity_refs.csv`, `derivative_fidelity_refs_summary.csv`, `derivative_identifiability.csv`.
Data: deduped `data/raw/718_all.csv` (7,938 rows = 98 compositions x 81 T). Fit: `get_split("random", seed)` for seeds 42-51 (n = 10), degree-5 polynomial on train+val (6,350 rows), minimum-norm solution. Model: analytic polynomial gradient at the same point, converted to raw units by the chain rule (`target_scale / feature_scale`). All numbers are mean ± std over seeds (population std). Previous outputs: `backup_pre_noise_budget/`.

Reference = central finite differences of the raw G table (narrow stencil, one grid step each side), unless a column says otherwise. The table is quantised: 37.9% of the G values (|G| >= 100000 J/mol) are integers (quantum 1 J/mol), the rest are multiples of 0.01 J/mol. Sections 4-6 budget that rounding noise per stencil from the actual quantum of every value in it, add a second reference that averages the noise down, and decide whether each headline error is model error or FD noise.

## 4. FD rounding-noise budget (all grid points, poly estimator)

`noise rms` = rms over the points of sqrt(sum_k (w_k q_k)^2 / 12): the stencil's rounding error, with q_k the quantum of each G value in that stencil. `noise/MAE` = noise rms / poly MAE (the old script's `rounding_over_mae` convention); `E|noise|/MAE` uses the expected mean absolute noise (Monte Carlo, 64 draws per stencil), the like-for-like comparison with an MAE. `noise/typical` = noise rms / typical |d|. `noise share` = noise rms^2 / mean((P - FD)^2), the share of the squared error that rounding noise could explain if it is independent of the model error. `implied model rms err` = sqrt(max(mean((P - FD)^2) - noise rms^2, 0)) / typical |d|, to be compared with `poly rms err` = sqrt(mean((P - FD)^2)) / typical |d|. `trunc/MAE` = stencil truncation proxy (the stencil applied to P's own values vs its analytic derivative) / MAE. ## 7. What the data can and cannot identify

- Design rank on the fit rows (centred, bias-free, what the minimum-norm solve sees) = **95 of 1,286** columns in all 10 seeds (fit_rank values: [95]). That is 96 of 1,287 with the bias column.
- Singular-value gap: smallest retained 2.86, largest dropped <= 2.1e-10.
- Structure: 6 (T-only monomials, shared) + 6 planes x 15 (monomials containing that element) = 96; matches the rank with the bias column. The data fills six (T, c_e) planes that meet on the base T-line.
- `null_frac` = share of the derivative functional's norm in the null space of the design. That part is not determined by the data, and minimum-norm sets it to zero. Its size is basis-dependent, but ~0 vs clearly nonzero is invariant.

| derivative | evaluated at | null_frac | verdict |
|---|---|---|---|
| d/dT | any plane | <= 1.4e-13 | identified |
| d/dc_e | plane e | <= 9.1e-13 | identified (in-plane only) |
| d2/dc_e2, d2/dc_e dT | plane e | <= 5.9e-13 | identified (in-plane only) |
| d/dNi (any order) | anywhere | 1.00-1.00 | **not identifiable** (constant column; the polynomial returns ~0 only because min-norm zeroes unconstrained terms) |
| d/dc_i, i != e | plane e, c_e off base | 0.71-0.968 (seed-mean of plane means) | **not identified** |
| d2/dc_i dc_j, i != j | plane e, c_e off base | 0.91-0.999 | **not identified** |
| any derivative off the six planes | | not computed | not identified |

- Because the function restricted to the planes is fully determined, the minimum-norm choice cannot change any in-plane derivative; only model bias and noise from the degree-5 form remain. Composition-gradient accuracy in section 2 is a statement about **own-axis derivatives on the sweep lines only**: nothing is claimed for cross-element gradients, Ni, or interior compositions.

## Caveats

- Rounding noise is modelled as independent uniform errors per table value; the table is a deterministic rounding of a smooth function, so this is a statistical budget, not a per-point bound. Table values may carry other upstream (solver) noise that this budget does not see.
- The truncation proxy is the stencil applied to the polynomial itself, so it is only as good as the polynomial's higher derivatives (poorest on the poorly fitted axes).
- The smoothing spline (dG/dT only) is the Newton-test truth: degree 4 with its smoothing level set for 0.3 J/mol noise on every row; it does not adapt to the 0.01 J/mol rows, and agreement with the polynomial may partly reflect shared smoothness. The wide FD ladder is the independent check.
- Seeds vary only the polynomial fit; the references and point sets are seed independent.

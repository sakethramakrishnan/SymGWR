## FD error budget (all grid points, poly estimator, narrow FD)

`noise rms` = rms over the points of the stencil's rounding error, sqrt(sum_k (w_k q_k)^2 / 12). `noise/MAE` = noise rms / poly MAE (= the old `rounding_over_mae`); `E|noise|/MAE` uses the expected mean absolute noise (Monte Carlo, 64 draws per stencil). `noise/typical` = noise rms / typical |d|. `noise share` = noise rms^2 / mean((P - FD)^2): the share of the squared error that rounding noise could explain if independent of the model error. `implied model rms err` = sqrt(max(mean((P - FD)^2) - noise rms^2, 0)) / typical, to compare with `poly rms err`. `trunc` = stencil truncation proxy (the stencil applied to P's own values vs its analytic Hessian), a proxy for the true G's truncation error. Flag = noise/MAE or trunc/MAE >= 25%. `FD(P) vs FD(G)` applies the same stencil to P and to G, so truncation largely cancels.

## Caveats

- Rounding noise is modelled as independent uniform errors per table value, a statistical budget rather than a per-point bound; the table may carry other upstream noise that it does not see. The d2G/dT2 prediction was checked against the spline in `second_order_reconciliation.md`; the other terms rely on the model.
- The truncation proxy is the stencil applied to the polynomial itself, so it is only as good as the polynomial's higher derivatives (weakest on the poorly fitted terms, which are exactly the ones in question).
- The smoothing spline (d2G/dT2 only) is the Newton-test truth: degree 4, smoothing level set for 0.3 J/mol noise on every row, so it does not adapt to the 0.01 J/mol rows; agreement with the polynomial may partly reflect shared smoothness.
- Composition-axis and mixed terms have short sweeps (11-26 nodes, uneven near the base value for Al and Fe), which caps the wide ladder; the common set C is smaller than the narrow-FD set there.
- Seeds vary only the polynomial fit; the references and point sets are seed independent.
